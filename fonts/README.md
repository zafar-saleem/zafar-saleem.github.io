# Switzer font

Switzer is free for commercial use but must be downloaded from Fontshare:
https://www.fontshare.com/fonts/switzer

1. Click "Download family" and unzip.
2. Copy `Switzer-Variable.woff2` (from the `Fonts/WEB/fonts` folder) into this directory.

Until the file is added, the site falls back to the system sans-serif font.
